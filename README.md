# Página de error 404

Aplicación Angular de una sola página con un mensaje 404 genérico y minimalista. Informa al visitante que la página no existe o ya no está disponible.

## Requisitos

- Node.js compatible con la versión de Angular CLI del proyecto
- npm

## Desarrollo local

```bash
npm install
npm start
```

Abre `http://localhost:4200/` en el navegador. Para generar la compilación de producción:

```bash
npm run build
```

El mensaje se encuentra en `src/app/app.html`; los estilos de la página están en `src/app/app.css` y `src/styles.css`.
